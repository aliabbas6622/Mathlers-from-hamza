# 08 Student UI Guide

Every student page must be documented here.

## Dashboard
- **Purpose:** Provide an overview of the student's progress and upcoming tasks.
- **Widgets:** Recent activity, upcoming competitions.
- **Cards:** Stats cards (Score, Rank).
- **Buttons:** "Start Practice", "View Profile".
- **Spacing:** standard 8-point grid.
- **Mobile:** Stacked cards.
- **Empty States:** "No recent activity".
- **Loading:** Skeletons for cards and widgets.
- **Errors:** "Failed to load dashboard data."

Repeat these specifications for:
- Profile
- Practice
- Challenges
- Competition
- Leaderboard
- Certificates
- Notifications
- Settings
