# 09 Admin UI Guide

Every page in the Admin portal must be documented here.

## Pages Overview
- Dashboard
- Students
- Schools
- Question Bank
- Practice Sets
- Tests
- Competitions
- Analytics
- Certificates
- Notifications
- Settings

## Common Elements on Every Page
Every admin page contains:
- Header
- Toolbar
- Search
- Filters
- Buttons (Actions)
- Table
- Drawer (for details or quick edits)
- Modals (for creating, deleting)
- Empty State
- Loading state (skeletons)
- Permissions check
