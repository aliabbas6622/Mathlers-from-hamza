# 12 Responsive Guidelines

Everything responsive.

## Breakpoints
- **Desktop:** Main experience, full layout. Sidebars visible.
- **Tablet:** Adjusted layouts, collapsed sidebars if space is constrained, grid adjustments.
- **Mobile:** Single column layouts, mobile menus.

## Component Adjustments
- **Navigation:** Switches from desktop top/sidebar to mobile bottom nav or hamburger menu drawer.
- **Sidebar:** Hidden behind a drawer toggle on mobile/tablet.
- **Tables:** Horizontally scrollable on small screens, or transformed into list/card views.
- **Cards:** Grid changes from 3-4 columns to 2 to 1 column based on viewport.
- **Forms:** Input fields take 100% width on mobile.
- **Analytics:** Charts become scrollable or change type if required for small screens.
