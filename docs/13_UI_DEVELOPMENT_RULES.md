# 13 UI Development Rules

This is the document every AI must read before creating a page.

## Rules
✅ Never create a page without Navbar.
✅ Never create a dashboard without statistics.
✅ Every page must contain breadcrumbs.
✅ Every management page must contain search.
✅ Every table must support filters.
✅ Every form must validate.
✅ Every destructive action requires confirmation.
✅ Every page must support loading states.
✅ Every page must support empty states.
✅ Every page must support error states.
✅ Never duplicate components.
✅ Always use reusable UI.
✅ Follow spacing system.
✅ Use only approved colors.
✅ Use only approved typography.
✅ Use only approved buttons.
✅ Follow accessibility.
✅ Keep consistency.
