# 11 Animations and Interactions

Documenting all valid animations. **Never over animate.**

## Valid Interactions
- **Hover:** Slight scale up or color shift for interactive elements.
- **Scale:** Button active states, card hover states.
- **Fade:** Used for tooltips, toasts, modals opening/closing.
- **Slide:** Used for mobile menus and drawers sliding in from edges.

## Components with defined animations
- **Drawer:** Slide from right or bottom.
- **Modal:** Fade in and slight scale up.
- **Sidebar:** Slide in (mobile), collapse width (desktop).
- **Cards:** Lift on hover (shadow increase, Y-axis translation).
- **Buttons:** Ripple effect or simple scale down on click.
- **Loading:** Skeleton pulses, spinners.
- **Transitions:** Page route changes (fade).

Everything must be documented here. Keep consistency across the app.
