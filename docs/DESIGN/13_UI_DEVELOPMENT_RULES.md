# 13 UI Development Rules

## 100+ Rules
- Never create a page without a page title.
- Always include breadcrumbs.
- Every management page needs search.
- Every table needs pagination.
- Every form validates.
- Every delete action requires confirmation.
- Every page has loading skeletons.
- Every page has empty states.
- Every dashboard starts with KPI cards.
- Every chart has legends.
- Every button uses approved variants.
- Only use design tokens. Never hardcode colors.
- Never duplicate components.
- Never use inconsistent spacing. Always use the 8-point spacing system.
- Follow accessibility. Maintain responsiveness.
